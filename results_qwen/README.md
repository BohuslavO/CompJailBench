# CompJailBench Qwen results

[MATRIX.md](MATRIX.md) contains the 4 × 4 AUROC matrix and links each cell to its source CSV. **(H)** marks a historical result carried forward from an earlier experiment. The other ten cells report new results on Qwen3‑32B‑AWQ. The matrix combines experiments with different evidence and model configurations.

This directory follows the layout and CSV contract of [results 4x4](../results%204x4/README.md) at commit [cdd91b9](https://github.com/BohuslavO/CompJailBench/tree/cdd91b94f7b201b8ba690f6c85a1b1dae0353282/results%204x4). The 16 original CSVs are preserved byte for byte in `raw/`. Thirteen `qwen_submission__*.csv` files add the verified submission rows. Some of those files export historical scores with richer provenance, so the filename alone does not establish the model used in a cell.

## Rebuild from CSV

```sh
cd results_qwen
python build_matrix.py
```

The builder reads `raw/` and [auroc_sources.csv](auroc_sources.csv), then rewrites `MATRIX.md`. The selector names one source CSV and exact metric for each cell, with an expected pair count and a provenance label. Scores are paired by task and routing strategy. The historical NARCBench text CSVs use separate `_collusion` and `_control` task IDs, which the builder maps to a shared pair ID.

AUROC compares every attack score with every control score in the complete-pair cohort, counting ties as half. It measures separation by assigned condition. The original descriptive tables remain below the AUROC matrix and report arm means, flag rates and differences.

To add a result, use `raw/<contributor>__<attack_method>__<defense_method>.csv`. The columns are `contributor`, `attack_method`, `defense_method`, `model`, `task_id`, `strategy`, `condition`, `metric_name`, `metric_value`, `n_samples`, `run_id` and `notes`. AUROC inputs require one finite score per trajectory and `n_samples=1`. Keep distinct experiments and scopes under distinct metric names. Update the selected CSV, metric, expected count and provenance for the affected cell in `auroc_sources.csv`, then rebuild. `convert_batch_run.py` preserves the original worked example.
